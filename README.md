# CS2640_Final_Project

## About The Project

This is Blackjack programmed in MIPS assembly as our group's CS 2640 **Final Project**. 
Our group members decided on this project as a means of entertainment and to see how much we
can apply our assembly knowledge using Assembly. 

NOTE: This project can ONLY be ran on MARS 4_5.

## How to Use It
When a player runs this project, this game intends for the user to get into a "gambling" kind of mindset.
It is meant for the user to be hooked and to achieve the highest score possible.

1. This game will use the MARS console as the primary way for the user to input variables to progress in the game. (Ex: Type 1 to continue drawing cards)
2. The player will frequently be asked to type into the console on MARS using inputs 1 or 2 to advance the game.
The game will keep printing that prompt until that user types in a VALID input.
